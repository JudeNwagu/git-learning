## What is Git?

**Git is a distributed version control system that tracks changes to files and project history over time.**

Git allows developers and other technical professionals to:

* Track changes to a project
* Review previous versions
* Create separate branches for new work
* Combine changes from different branches
* Collaborate with others
* Synchronize work with remote repositories

Git was created in 2005 by Linus Torvalds to support the development of the Linux kernel.

---

## Git vs GitHub

Git and GitHub are related, but they are not the same thing.

| Git                                   | GitHub                                                       |
| ------------------------------------- | ------------------------------------------------------------ |
| A distributed version control system  | A platform for hosting and collaborating on Git repositories |
| Primarily runs on your local computer | Primarily provides online services                           |
| Tracks changes and project history    | Hosts repositories and supports collaboration                |
| Can be used without GitHub            | Works with Git repositories                                  |

### Simple way to remember

```text
Git      → Tracks your project's history
GitHub   → Hosts Git repositories and supports collaboration
```

## How Git Works

The basic Git workflow can be represented as:

```text
Working Directory
      │
      │ git add
      ▼
Staging Area
      │
      │ git commit
      ▼
Local Repository
      │
      │ git push
      ▼
Remote Repository
```

### The workflow

1. I create or modify files in my **working directory**.
2. I select changes for my next commit using `git add`.
3. The selected changes move to the **staging area**.
4. I create a commit using `git commit`.
5. The commit is stored in my **local repository**.
6. I use `git push` to send my local commits to a **remote repository**.

> **Important:** `git commit` saves changes locally. `git push` sends committed changes to a remote repository.
